# Contributing to SkillOps Website

Thank you for contributing to the official **SkillOps** web showcase (`@skillops-toolkit/skillops-website`).

## Governance & Pull Request Rules

1. **Branch Naming**: Must follow `<type>/<short-kebab-description>` (e.g., `feat/catalog-filter`, `fix/header-scroll`, `docs/readme-update`).
2. **PR Title**: Must follow **Conventional Commits** in English lowercase imperative (e.g., `feat(ui): add interactive manifest preview`).
3. **Code Owners**: Every Pull Request requires review and approval from `@OdevMatheus` via `.github/CODEOWNERS`.
4. **Data Hygiene**: Never commit local machine paths, `.env` files, or API keys.
5. **Contributing Skills & Subagents**: To contribute a new `SKILL.md` or `SUBAGENT.md` to the CLI catalog, open a Pull Request in the main repository: **[skillops-toolkit/SkillOps](https://github.com/skillops-toolkit/SkillOps)**.
